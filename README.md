# huree.ru — Устуу-Хурээ

Сайт буддийского храмового комплекса «Устуу-Хурээ» (Республика Тыва, урочище Чайлаг-Алаак, 7 км от Чадана).

Статический сайт без сборки: чистый HTML + CSS + JS, хостинг — GitHub Pages.

## Структура

- `index.html` — Обитель: история (1905 → 1930-е → 2012), ламы, реликвии, цитата
- `huraly.html` — Расписание молебнов, форма записки, лунный календарь
- `novosti.html` — Новости с фильтрами по категориям, подписка
- `palomnikam.html` — Памятка паломнику: этикет, прием лам, дорога, контакты
- `admin.html` — Админ-панель (редактирование контента и фото)
- `data.json` — весь редактируемый контент сайта
- `assets/` — css, js, шрифты (self-hosted), иконки (SVG-спрайт), изображения

## Админ-панель

1. Откройте `https://<домен>/admin.html`
2. Пароль входа задаётся хэшем SHA-256 в `assets/js/admin.js` (CONFIG.passHash).
   Текущий пароль задаётся при деплое — смените его при необходимости:
   ```js
   node -e 'console.log(require("crypto").createHash("sha256").update("НОВЫЙ_ПАРОЛЬ").digest("hex"))'
   ```
3. Редактируйте тексты, добавляйте/удаляйте записи (хуралы, новости, ламы, реликвии, правила), загружайте фото (кнопка «Загрузить фото» в каждом поле изображения или раздел «Медиатека»).
4. «Опубликовать изменения» коммитит `data.json` в репозиторий через GitHub API.
   При первом publishing браузер запросит Personal Access Token (scope: `repo`).
   Токен вводится один раз за сессию, хранится только в sessionStorage браузера.

После публикации сайт обновляется через 1–2 минуты (кэш GitHub Pages).

## Технические решения

- Дизайн-система «Ustuu-Khuree Monastic Serenity»: ivory/sand/linen-палитра, монашеский бордо `#6B0D0A`, терракота `#9E4300`, шафрановое золото `#C8832A`
- Шрифты: **Onest** (заголовки; замена Epilogue — у неё нет кириллицы) + **Manrope** (текст), self-hosted woff2
- Иконки: Material Symbols, скачанные как inline SVG-спрайт (`assets/icons/sprite.svg`, 35 иконок, ~17 КБ)
- Mobile-first: нижняя таб-навигация на мобильных; ≥768px — горизонтальное меню + телефон
- Доступность: aria-атрибуты, контраст AAA, крупные тач-цели (48px+), focus-visible

## Развёртывание (GitHub Pages)

1. Репозиторий: `huree.ru`
2. Settings → Pages → Deploy from branch → `main` / root
3. Кастомный домен: добавить DNS-записи для `huree.ru` → `Aymet5.github.io` и файл CNAME при необходимости
